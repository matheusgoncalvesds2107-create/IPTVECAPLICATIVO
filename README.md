# IPTVEC — versão nova

Projeto criado do zero, com interface própria e núcleo simples:
- Android 7.0+ (minSdk 24)
- Player HLS/M3U8
- Leitura de arquivo M3U/M3U8
- Campo para URL M3U
- Categorias por group-title
- Busca de canais
- Tela cheia
- GitHub Actions pronto em `.github/workflows/build-apk.yml`

Observação: a versão base não inclui credenciais de uma lista IPTV externa. A URL pode ser informada pelo usuário no aplicativo.
